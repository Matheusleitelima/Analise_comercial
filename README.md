Este projeto foi desenvolvido com o objetivo de simular um fluxo completo de análise de dados na área comercial, passando pelas etapas de extração, tratamento e visualização de dados.

A base de dados contém informações sobre cursos, clientes, professores, valores financeiros e atuação do time comercial. A partir disso, foi construída uma pipeline simples utilizando SQL, Python (Pandas) e Power BI, com foco em gerar indicadores relevantes para o negócio.

No processo, os dados foram inicialmente carregados em uma tabela de staging no banco de dados, garantindo uma camada bruta para posterior manipulação. Em seguida, utilizando Python e Pandas, foi realizado o tratamento dos dados, incluindo padronização de colunas, limpeza de valores monetários e criação de métricas como lucro e despesas.

Após o tratamento, os dados foram exportados e utilizados no Power BI para construção de um dashboard interativo, permitindo a análise de indicadores como:

Valor total de vendas
Total de despesas
Lucro total
Quantidade de matrículas

Este projeto demonstra habilidades essenciais para a área de dados, como:

Manipulação e limpeza de dados com Pandas
Criação de queries e estruturação de dados com SQL
Modelagem de métricas com DAX no Power BI
Pensamento analítico voltado para negócios
